# Screen mockups

Twelve phone screens, 390 by 844, with sample data. The live, clickable version is on the design
canvas at https://claude.ai/artifact/CHdtAQGNSxcU7Jh1dCcsHb (private to the owner until shared).

These files are the canvas sources. Each `.dc.html` is one screen; `canvas.json` is the layout. They
reference a runtime script from the canvas and will not render standalone, but the markup and inline
styles are the reference for the real app's colors, spacing, type, and copy.

| File | Screen |
|---|---|
| Main.dc.html | Today, with the day forecast and component panels each in its own tier color |
| Checkin.dc.html | Voice check-in |
| Journal.dc.html | Journal, cravings strip, spoken symptoms, tarot pull, photos |
| Timeline.dc.html | Days, forecast dots and one night on one clock |
| Sky.dc.html | Sky and earth: moon and transits, weather, pressure, air, sky events, ground |
| Insights.dc.html | Patterns feed |
| Profile.dc.html | Me: profile and hormonal context |
| Experiment.dc.html | Experiment runner |
| Welcome.dc.html | First run, two doors |
| Feel.dc.html | How you feel: texture, tempo, tint |
| Goals.dc.html | Goals, habit tracker, timer |
| Settings.dc.html | Settings with the assistant master switch |
